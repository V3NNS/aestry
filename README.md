## AU — Modo Escondite

### Reglas de las pruebas 1 vs 1

1. La prueba consta de **7 rondas**, cada una en un mapa diferente.
2. El tester elige los mapas de las rondas **1, 3, 5 y 7**.
3. El jugador elige los mapas de las rondas **2, 4 y 6**.
4. Los mapas deben ser válidos para el modo Escondite y aceptados por ambos.
5. Está prohibido usar hacks, cheats o cualquier ventaja injusta.
6. No se permite recibir ayuda ni información de espectadores.
7. No abandones la prueba para evitar el resultado. Si alguien se desconecta, el tester decide si se repite la ronda.
8. Mantengan el respeto durante toda la prueba.
9. Durante toda la prueba, comparte tu pantalla en Discord para que el tester pueda ver la partida.
